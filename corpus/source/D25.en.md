# Configuration reference: sq-store

This document lists the configuration keys for the event store in SENTRIQ 4.2.
Keys are set in the store cluster configuration and require a rolling restart.

## Keys

| Key | Type | Default | Description |
|---|---|---|---|
| `store.retention_days` | int | 90 | Days of telemetry retained before deletion. |
| `store.shard_replicas` | int | 2 | Replica count per shard. |
| `store.retention_job_window` | duration | 4h | Nightly window for the retention job. |
| `store.disk_high_watermark` | percent | 85 | Disk usage above which shards stop allocating. |

## Notes

The replica count and the number of live nodes together decide whether shards can
be assigned; requesting more replicas than live nodes causes `SQ-6008` (see D09).
A retention job that cannot finish inside its window reports `SQ-6014` and lets
disk approach the high watermark, past which shards go unassigned (see D17).
