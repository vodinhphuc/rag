# Runbook: Agent báo offline

Quy trình xử lý khi endpoint hiển thị Offline trên Console.

## Triệu chứng

- Endpoint ở trạng thái **Offline** trên Console.
- Alert `SQ-1004` — không nhận được heartbeat từ agent.
- Endpoint vẫn hoạt động bình thường.

## Quy trình xử lý

**Bước 1 — Kiểm tra service trên endpoint**

```
sc query sq-agent          # Windows
systemctl status sq-agent  # Linux
```

Nếu service đang chạy mà vẫn báo offline, chuyển sang Bước 2.

**Bước 2 — Restart collector**

Phần lớn trường hợp agent báo offline hàng loạt là do session phía collector
không được giải phóng. Restart collector để xử lý các session cũ:

```
systemctl restart sq-collector
```

Sau khi restart, agent sẽ tự động kết nối lại trong vòng 2 – 3 phút. Theo dõi số
lượng endpoint online trên Console trong thời gian này.

**Bước 3 — Restart agent trên endpoint**

Nếu sau Bước 2 vẫn còn endpoint offline, restart agent trên từng máy còn lại:

```
sc stop sq-agent && sc start sq-agent
```

**Bước 4 — Kiểm tra certificate**

Nếu agent vẫn không kết nối được, kiểm tra hạn certificate trong log agent.

## Ngưỡng escalate

Escalate cho team Endpoint nếu sau Bước 3 vẫn còn trên 50 endpoint offline.

## Ghi chú

Thao tác restart collector nên thực hiện ngoài giờ cao điểm nếu có thể. Trường
hợp khẩn cấp có thể thực hiện bất kỳ lúc nào.

Chủ sở hữu component: team Endpoint.
