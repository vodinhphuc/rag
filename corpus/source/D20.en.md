# Agent error dialog — certificate expired

Shown on the endpoint when the agent cannot present a valid certificate.

```
┌──────────────────────────────────────────────┐
│  Sentriq Agent                          [ X ] │
├──────────────────────────────────────────────┤
│   ⚠  Connection failed                        │
│                                               │
│   mTLS handshake failed:                      │
│   certificate expired                         │
│                                               │
│   Error code:  SQ-1017                        │
│   Endpoint:    WIN-KT2291                      │
│   Cert expiry: 2026-01-04 (16 days ago)       │
│                                               │
│   Action: run 'sentriqctl cert renew --force' │
│           or contact your administrator.      │
│                                               │
│                              [ Retry ]  [ OK ] │
└──────────────────────────────────────────────┘
```

The exact error string (`certificate expired`), the code (`SQ-1017`) and the
suggested command are all inside this dialog image. An operator pasting a photo of
this screen is pasting the only place these details appear together.
