# Port and firewall reference

Applies to SENTRIQ 4.2. Every network path the product needs, per direction.
Rendered as a workbook: the port table and the timeout table are separate sheets.

## Network ports

| From | To | Port | Protocol | Notes |
|---|---|---|---|---|
| agent | sq-collector | 8443 | mTLS | Telemetry upload |
| sq-collector | sq-store | 9200 | TLS | Event write |
| sq-console | sq-detect | 8080 | TLS | Rule evaluation |
| agent | sq-policy | 7443 | mTLS | Policy and certificate pull |
| agent | sq-relay | 8843 | TLS | Signature and version updates |
| sq-console | sq-store | 9200 | TLS | Telemetry query |

## Timeouts and intervals

These are the defaults. Changing them requires a policy push and takes effect at
the next agent check-in.

| Setting | Component | Default | Configurable |
|---|---|---|---|
| Heartbeat interval | agent | 5 minutes | yes |
| Heartbeat miss threshold | agent | 15 minutes | yes |
| Certificate lifetime | sq-policy | 90 days | no |
| Certificate auto-renew window | sq-policy | 30 days | no |
| Collector queue threshold | sq-collector | 50,000 events | yes |
| Store retention | sq-store | 90 days | yes |
| Console idle timeout | sq-console | 30 minutes | no |

## Firewall notes

All paths are outbound from the agent's perspective except the console paths.
The agent never accepts inbound connections — a common misconception during
onboarding. If an endpoint cannot reach port 7443, certificate renewal fails
silently until the certificate expires; see D07.
