# SENTRIQ service dependency map

Direct connections between components. An arrow means the source opens a
connection to the target.

```
   agent  ─8443─►  sq-collector  ─9200─►  sq-store  ◄─9200─  sq-console
     │                                                          │
     ├─7443─►  sq-policy                       sq-console ─8080─►  sq-detect
     │                                                          
     └─8843─►  sq-relay                        sq-detect  reads  sq-store
```

## Reads the store

Only **sq-collector** (writes) and **sq-console** and **sq-detect** (read) connect
to sq-store. The agent, sq-policy and sq-relay never talk to the store directly —
they have no path to it. A question about "what talks to the store" has exactly
these three answers and no others.

## Reaches the endpoint

Only sq-policy (policy and certificates, 7443) and sq-relay (updates, 8843) push
to the agent. The agent initiates all other connections outbound.

## Single points of failure

sq-store is the only four-node cluster; every other component is one to three
nodes. The console is not on the telemetry path, so its failure does not stop
collection or detection.
