# Agent installation guide (Windows)

Applies to SENTRIQ 4.2 on Windows 10, 11 and Server 2019+. Follow the steps in
order; several are order-dependent and a later step assumes the earlier one
completed.

## Prerequisites

- Local administrator rights on the target endpoint.
- Network reachability to sq-policy on port 7443 and sq-collector on port 8443.
- The enrolment token from Console → Fleet → Enrolment.

## Step 1 — Verify connectivity

Before installing, confirm the endpoint can reach the policy service. If it
cannot, the agent installs but never enrols, which looks like a failed install
when it is actually a firewall problem.

```
Test-NetConnection sq-policy.internal.norvale.test -Port 7443
```

## Step 2 — Run the installer

Run the MSI with the enrolment token. The token binds the agent to your fleet and
requests its first certificate from sq-policy.

```
msiexec /i SentriqAgent-4.2.msi /quiet ENROL_TOKEN=<token>
```

## Step 3 — Confirm enrolment

The agent requests a certificate on first start. Enrolment is complete when the
service is running and the certificate is present. This can take up to two
minutes on first contact.

```
sc query sq-agent
sentriqctl cert show
```

## Step 4 — Verify telemetry

Confirm the endpoint appears Online in the Console within five minutes. If it does
not, the agent is running but not reaching the collector; check port 8443 before
reinstalling.

## Step 5 — Apply policy

The agent pulls its policy from sq-policy after enrolment. Confirm the expected
policy is applied under Console → Fleet → the endpoint → Policy. A newly enrolled
agent uses the default policy until the group policy is pulled.

## Uninstall

Uninstalling requires the same token or an admin override, by design — tamper
protection prevents a local user from removing the agent. Remove it from the
Console (Retire) rather than locally where possible.

## Troubleshooting

If the endpoint shows Offline after install, it is one of: service not running
(Step 3), cannot reach the collector (Step 4), or certificate not issued (Step 3).
See the offline runbook D06.
