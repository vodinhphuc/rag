# Configuration reference: sq-detect

This document lists the configuration keys for the detection engine in SENTRIQ
4.2. Keys are set in the detection node configuration and require a service
restart.

## Keys

| Key | Type | Default | Description |
|---|---|---|---|
| `detect.correlation_window` | duration | 15m | Maximum window for correlating events. |
| `detect.rule_bundle` | string | (config) | Active rule bundle version. |
| `detect.max_alerts_per_rule` | int | 1000 | Per-rule alert cap per hour before suppression. |
| `detect.eval_workers` | int | 4 | Parallel rule-evaluation workers. |

## Notes

A correlation window longer than the configured maximum reports `SQ-3021`
(correlation window overflow), which is a capacity problem distinct from a rule
compilation failure (`SQ-3009`, see D11). The per-rule alert cap is what stops a
noisy rule from overwhelming the console; tuning it is part of false-positive
handling (see D14).
