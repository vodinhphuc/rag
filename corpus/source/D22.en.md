# Configuration reference: sq-collector

This document lists the configuration keys for the collector in SENTRIQ 4.2. All
keys are set in the collector node configuration and require a service restart.

## Keys

| Key | Type | Default | Description |
|---|---|---|---|
| `collector.queue_threshold` | int | 50000 | Queue depth above which agents are throttled. |
| `collector.drain_rate` | int | 5000 | Events per second when draining the backlog. |
| `collector.store_endpoint` | string | (config) | Event store host and port. |
| `collector.buffer_limit` | duration | 20m | How long telemetry is held when the store is unreachable. |
| `collector.normalise_workers` | int | 8 | Parallel normalisation workers. |

## Notes

The queue threshold and drain rate are the two values most often tuned during a
back-pressure incident (`SQ-2011`, see D08). The buffer limit is the window past
which telemetry is dropped rather than held; it is also the time budget during a
store outage (`SQ-6008`, see D09).
