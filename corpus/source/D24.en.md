# Configuration reference: sq-policy

This document lists the configuration keys for the policy service in SENTRIQ 4.2.
Keys are set in the policy service configuration and require a service restart.

## Keys

| Key | Type | Default | Description |
|---|---|---|---|
| `policy.cert_lifetime` | duration | 90d | Certificate validity issued to agents. |
| `policy.cert_renew_window` | duration | 30d | Window before expiry in which agents auto-renew. |
| `policy.push_batch_size` | int | 500 | Endpoints per policy-push batch. |
| `policy.exclusion_max_ttl` | duration | 14d | Maximum time-to-live for a temporary exclusion. |

## Notes

The certificate lifetime and renew window are fixed defaults not changeable per
policy; they explain why a machine offline for the whole renew window hits
`SQ-1017` (see D07). The exclusion maximum TTL enforces that temporary exclusions
expire; exclusions without an expiry are the common cause of `SQ-5013` conflicts
(see D10).
