# Configuration reference: sq-agent

This document lists the configuration keys for the Sentriq Agent in SENTRIQ 4.2.
All keys are set via policy and take effect at the next check-in.

## Keys

| Key | Type | Default | Description |
|---|---|---|---|
| `agent.heartbeat_interval` | duration | 5m | Interval between heartbeats to the collector. |
| `agent.collector_endpoint` | string | (policy) | Collector host and port. |
| `agent.realtime_scan` | bool | true | Enable real-time file scanning. |
| `agent.telemetry_level` | enum | standard | One of minimal, standard, verbose. |
| `agent.tamper_protection` | bool | true | Prevent local removal of the agent. |
| `agent.update_channel` | enum | ga | One of ga, rc. |

## Notes

Values are validated at policy push. An invalid value rejects the policy push
with `SQ-5006`. Tamper protection cannot be disabled by policy alone; it also
requires a console-side override.
